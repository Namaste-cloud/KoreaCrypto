# KoreaCrypto (국내 금융권 디지털자산 사업·정책 모니터링 시스템)

**주 이용자:** KB증권 STO 및 기관 디지털자산 사업 담당자  
**시스템 목적:** 국내 금융회사의 디지털자산 사업 동향, 생태계 파트너십, 추진 단계 및 금융위원회/한국은행 정책·제도 여건을 지속적이고 체계적으로 검증·모니터링

---

## 1. 주요 기능 및 5대 핵심 화면

1. **종합 현황 (`/`)**
   - 조사 범위 및 기준일, 3종 수집 시각(시도/성공/데이터변경)
   - 최근 주요 변화 및 확인된 진전 (원천 근거 모달 연결)
   - 사업 분야별 프로젝트 분포 및 다가오는 정책 마일스톤
   - KB증권 STO 포커스 분석 (KB STO V2, 캔톤 네트워크, 시큐리타이즈·옵티미즘)

2. **기업·프로젝트 (`/companies`)**
   - 21개 주요 금융기관·수탁사·핀테크 및 11개 핵심 프로젝트 정밀 분석
   - 사업상 의미: [확인된 사실] vs [사업상 분석] vs [미확인 사항] 엄격 분리
   - 2~4개 기업 간 다자간 사업 비교(Compare) 기능
   - 전체 데이터 CSV 내보내기(Export)

3. **생태계 관계도 (`/relations`)**
   - 인터랙티브 네트워크 그래프 (SVG 기반 줌/팬/드래그 지원)
   - 중심 대상 선택에 따른 1차 관계망 동적 재구성
   - 연결선(Edge) 클릭 시 원천 근거 및 역할 상세 패널 표출
   - 동일 데이터의 표(Table) 모드 전환 지원

4. **정책·제도 현황 (`/policies`)**
   - 토큰증권 제도화 법안(2027.2.4 시행), 하위법규 입법예고, 원화 스테이블코인 정부안, 프로젝트 한강 2단계 규제특례 등
   - 발의·심사·의결·공포·시행 등 확인된 법적 단계 타임라인
   - 연계 프로젝트(직접 적용 vs 향후 영향 가능) 매핑 및 정부 공식 원문 링크

5. **변경 이력 & 검토 대기열 (`/changelog`)**
   - 변경 전/후 상태, 원천 근거, 반영 방식(자동/검토) 기록
   - 출처 간 충돌이나 불명확한 기사를 격리하는 검토 대기열(Review Queue)
   - Git 이력 기반 과거 기록 시점별 복구 가능

## 2. 조사 범위 및 검증 원칙

- **조사 완료 기관 (21개사):**
  - **증권:** KB증권, 미래에셋증권, 신한투자증권, 하나증권, 한국투자증권, NH투자증권, 우리투자증권, 키움증권, 메리츠증권, 유진투자증권, 코스콤
  - **은행·지주:** KB국민은행, 신한은행, 하나은행, 한국은행, KB금융지주, 신한금융지주, 하나금융지주, 미래에셋그룹
  - **수탁사:** 한국디지털에셋(KODA), 한국디지털자산수탁(KDAC), 비댁스(BDACS), 비트고코리아(BitGo Korea)
  - **핀테크·글로벌:** 캔톤 재단, 시큐리타이즈, 옵티미즘 재단, 리플, 테사, 스탁키퍼, 디지털엑스(구 코빗), 두나무(업비트), 웨이브릿지
- **원칙:**
  - 공개자료가 없다는 이유로 사업 미추진으로 단정하지 않음.
  - MOU는 단순 협약일 뿐 PoC나 상용화로 간주하지 않음.
  - 최종 확인일로부터 180일이 경과한 정보는 '확인필요(오래된 정보)' 라벨 표시.

## 3. 자동 갱신 및 운영 구조

- **스케줄러:** 매 1시간마다 자동 실행 (`.github/workflows/daily_collect.yml`, 매시 정각)
- **수집 스크립트:** `scripts/collector.py`
- **상태 보존:** 수집 실패 시 기존 데이터를 안전하게 보존하며, `status.json`에 시각 기록 분리
  - `lastAttemptAt`: 마지막 수집 시도 시각
  - `lastSuccessAt`: 마지막 정상 수집 완료 시각
  - `lastDataChangeAt`: 실제 데이터 변경이 발생한 시각

## 4. 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 프로덕션 빌드
npm run build

# 서버 실행 (포트 3088)
npm run start -- -p 3088

# 자동 수집 테스트
python3 scripts/collector.py
```
